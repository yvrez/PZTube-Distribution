# PZTube

Installateurs officiels de PZTube pour **Project Zomboid 42.20 Stable** sous
Windows 64 bits.

## Télécharger

[Télécharger le Web Setup recommandé](https://github.com/yvrez/PZTube-Distribution/releases/latest/download/PZTube-WebSetup-0.1.14-B42.20.exe)

La [dernière release](https://github.com/yvrez/PZTube-Distribution/releases/latest)
contient également l’installeur complet hors ligne et les empreintes SHA-256.

Le Web Setup fait moins de 500 Kio. Il télécharge des versions épinglées de mpv
et yt-dlp depuis leurs releases GitHub, vérifie leurs empreintes SHA-256 puis
conserve les fichiers dans un cache local pour les réinstallations.

## Installation

1. Fermer Project Zomboid.
2. Lancer `PZTube-WebSetup-0.1.14-B42.20.exe`.
3. Utiliser le raccourci **PZTube - Project Zomboid** créé sur le Bureau.

Tous les joueurs d’un serveur doivent installer exactement la même version de
PZTube. Le code source du projet reste privé pendant la phase de test.
